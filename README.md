# Green Zone Nature Ayurveda Landing Page

यह **Green Zone Nature Ayurveda** का प्रीमियम, हाई-कन्वर्शन और पूरी तरह से रिस्पॉन्सिव लैंडिंग पेज है, जिसे मधुमेह (Diabetes) और शुगर के मरीजों के लिए विशेष रूप से डिज़ाइन किया गया है।

## 📋 विशेषताएँ (Features)
*   **100% रिस्पॉन्सिव डिज़ाइन:** मोबाइल, टैबलेट और डेस्कटॉप स्क्रीन पर परफेक्ट रेंडरिंग।
*   **3-स्टेप कंसल्टेशन विज़ार्ड:** मरीजों के विवरण (नाम, फ़ोन, शुगर लेवल, और लक्षण) एकत्र करने के लिए एक इंटरैक्टिव फॉर्म।
*   **Google Sheet इंटीग्रेशन:** फॉर्म सबमिट होते ही डेटा सीधे आपकी गूगल शीट में सेव हो जाता है।
*   **लोकल डेटाबेस (Admin Panel):** सभी लीड्स ब्राउज़र के लोकल स्टोरेज में सेव होती हैं, जिन्हें `Ctrl + Alt + A` दबाकर पासवर्ड-प्रोटेक्टेड टेबल में देखा जा सकता है।
*   **व्हाट्सएप ऑटो-रीडायरेक्ट:** फॉर्म सबमिट करने के बाद मरीज के भरे हुए विवरण के साथ सीधे व्हाट्सएप चैट पर भेजने की सुविधा।

## 🚀 लोकल सर्वर पर कैसे चलाएं? (How to Run)
प्रोजेक्ट को लोकल कंप्यूटर पर चलाने के लिए नीचे दिए गए तरीकों में से किसी एक का उपयोग करें:

### तरीका 1: Node.js (npx serve)
यदि आपके कंप्यूटर पर Node.js इंस्टॉल है, तो प्रोजेक्ट फ़ोल्डर के अंदर टर्मिनल में यह कमांड चलाएं:
```bash
npx serve
```
यह प्रोजेक्ट को `http://localhost:3000` या `http://localhost:5000` पर होस्ट कर देगा।

### तरीका 2: Python (HTTP Server)
यदि आपके पास पायथन इंस्टॉल है, तो यह कमांड चलाएं:
```bash
python -m http.server 8000
```
इसके बाद ब्राउज़र में `http://localhost:8000` खोलें।

## 📦 गिटहब पर कैसे पुश करें? (How to Push to GitHub)
सारे कोड को अपने गिटहब रिपोजिटरी पर पुश करने के लिए, अपने टर्मिनल में नीचे दी गई कमांड चलाएं:
```bash
git add README.md
git commit -m "docs: add README.md with setup instructions"
git push -u origin main
```
